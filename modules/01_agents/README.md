# Module 1 — Agents and problem representation

What is artificial intelligence, and how do you describe a system that perceives the world and acts in it? This module introduces the rational agent, how to describe its task and environment, the types of agents, and how to write a task down as a problem a computer can solve.

## Module goals

After this module you will be able to:

- explain the different views of AI and the rational agent;
- describe an agent and its environment (PEAS, properties of environments);
- implement a simple reflex agent and see its limits;
- formulate a task as a search problem and count its states.

## How the lessons connect

- **1.2 → 1.3: the same parcel world in two representations.** First from the point of view of an agent that has only a local percept. Then as the full state of a search problem.
- **1.3 → module 2.** A problem formulation is the input to search algorithms. The state-space explosion from lesson 1.3 comes back in modules 2 and 4.
